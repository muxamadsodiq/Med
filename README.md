# Med

A modern medical management system built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- **Dashboard** – Overview of key metrics (patients, appointments, doctors, reports)
- **Appointments** – Schedule and manage patient appointments with status filtering
- **Doctors** – Browse medical staff profiles with specialty, experience, and availability
- **Patients** – Search and manage patient records

## Tech Stack

| Package | Version |
|---|---|

| TypeScript | ^6.0.2 |
| Vite | ^8.0.3 |

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
